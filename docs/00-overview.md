# 프로젝트 개요

## 프로젝트 한줄

MeetingNote - 회의록 자동 정리 풀스택 웹앱

## 6개 파일 매핑표

| 파일명 | 역할 | 알 수 있는 것 |
|---|---|---|
| `00-overview.md` | 프로젝트 전체 개요 | 프로젝트 목적, 문서 체계, 읽는 순서와 관심사 분리 원칙 |

## 읽는 순서

`00` > `01` > `02` > `03` > `04` > `05`

## 왜 이렇게 나누는가

문서를 관심사 분리 원칙에 따라 나누면 프로젝트의 목적, 제품 요구사항, 구체적인 명세, 기술 설계, 실행 작업, 개발 규칙을 서로 섞지 않고 관리할 수 있다. 각 문서는 하나의 관심사에 집중하므로 변경 범위를 예측하기 쉽고, 필요한 정보만 빠르게 찾을 수 있다. 또한 상위 문서에서 정한 방향이 하위 문서의 기준이 되어 요구사항과 구현 사이의 추적성을 유지할 수 있다.
