## 진행 규칙

- Phase 이름과 단계 수는 변경하지 않는다.
- Phase 1은 10단계, Phase 2는 10단계, Phase 3은 8단계로 고정한다.
- 각 Phase의 체크리스트는 순서대로만 진행한다.
- 단계를 병렬로 진행하지 않는다.
- 각 단계 완료 전 필수 검증을 수행한다.
- 검증이 통과된 단계만 `[x]`로 변경한다.
- `backend 진행해`는 Phase 2 전체 진행을 뜻한다.
- `frontend 진행해`는 Phase 3 전체 진행을 뜻한다.
