# 01. 제품 정의

## 목표

**회의가 끝나면 정리가 끝나 있게.** 「그때 뭐라고 했더라」가 사라지게 한다.

## 페르소나

- 주 3회 이상 회의에 들어가는 **실무자**
- 30~50대, **개발자 아님**

## MVP 범위

| # | 기능 | 세부 |
|---|---|---|
| 1 | 입력 | 녹취 파일 업로드 (mp3, wav, **25MB 이하**) 또는 메모 붙여넣기 |
| 2 | 세 갈래 구분 | 받아쓴 본문을 **요약 / 결정사항 / 할 일** 세 갈래로 구분 |
| 3 | 회의록 CRUD | 4종 모두 화면에서 - 추가 / 목록 / 수정 / 삭제 |
| 4 | 검색 | 제목, 참석자, 날짜로 검색 |
| 5 | 할 일 모아 보기 | 할 일만 모아 보는 화면 (담당자, 기한 표시) |
| 6 | 테마 | 라이트 / 다크 테마 토글 (localStorage 에 저장) |
| 7 | 반응형 | 모바일 360px 에서 동작 |

## UI 톤

**Mac OS 스타일**

- 둥근 모서리
- 부드러운 그림자
- 반투명 카드
- 시스템 폰트

## 확장 (MVP 이후)

- JWT 로그인
- 팀 공유
- 화자 이름 수동 지정
- 알림
- 25MB 넘는 파일의 분할 업로드 (확장 단계로 보류)

## 범위 외 (만들지 않음)

- 실시간 녹음
- 화자 자동 구분
- 외부 캘린더 연동
- 메일 발송

> 25MB 넘는 파일은 MVP 에서 받지 않는다. 분할 업로드는 확장 단계로 보류한다.

## 성공 기준

실습에서 **눈으로 확인할 수 있는 것만** 둔다.

- [ ] 녹취 파일 하나가 세 갈래(요약 / 결정사항 / 할 일)로 구분되어 저장된다
- [ ] 새로고침해도 유지된다
- [ ] 360px 에서 안 깨진다
- [ ] 검색으로 지난 회의를 찾는다
