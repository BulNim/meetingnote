# 03. 설계

## 1. 기술 결정

| # | 항목 | 선택 | 대안 | 근거 | 트레이드오프 |
|---|---|---|---|---|---|
| 1 | 백엔드 | FastAPI | Django, Express | 타입 힌트와 Pydantic 으로 검증이 선언형이고, API 7개 규모에 맞게 가볍다. pytest + httpx 로 테스트하기 쉽다 | Django 의 관리자 화면 · 인증 같은 기본 제공 기능이 없어 필요하면 직접 만든다 |
| 2 | 프론트 | Vanilla JS + Tailwind CDN. 백엔드가 **같은 오리진**에서 제공한다. `file://` 로 직접 열지 않는다 | React, Vue | 화면 4종 · 파일 2개(`index.html` · `app.js`) 규모라 빌드 도구 없이 바로 돈다. 같은 오리진이라 CORS 설정이 필요 없다 | 화면이 커지면 상태 · 컴포넌트 관리를 손으로 해야 한다 |
| 3 | DB | SQLite (SQLAlchemy ORM, 추후 PostgreSQL 전환 고려) | PostgreSQL 즉시 도입 | 파일 하나라 설치 · 운영이 없다. ORM 을 거치므로 나중에 PostgreSQL 로 옮기기 쉽다 | 동시 쓰기에 약하다. SQLite 전용 동작(AUTOINCREMENT 등)은 전환 때 다시 확인해야 한다 |
| 4 | CSS | Tailwind 만. **styled-components 금지** | styled-components, 직접 CSS | 클래스만으로 스타일이 끝나 파일 2개 제약을 지킨다. CDN 이라 빌드가 없다 | CDN 판은 쓰지 않는 클래스까지 내려받아 무겁고, HTML 클래스 목록이 길어진다 |
| 5 | 받아쓰기 | Gemini API (`gemini-3.1-flash-lite`). 키는 **`.env` 로만** 읽고 저장소에 올리지 않는다 | Whisper 자체 구동, 브라우저 음성 인식 | 받아쓰기와 세 갈래 구분을 한 서비스로 처리한다. GPU · 모델 설치가 필요 없다 | 외부 호출이라 비용 · 지연 · 장애(429 · 503)에 묶인다. 녹취가 외부로 나간다 |
| 6 | 상태관리 | 모듈 변수 + DOM 직접 갱신 | 상태관리 라이브러리, 프레임워크 반응성 | 의존성이 없고, 화면 4종 규모에서는 흐름을 그대로 따라 읽을 수 있다 | 상태와 화면을 맞추는 일을 직접 해야 하고, 갱신을 빠뜨리면 화면이 어긋난다 |
| 7 | 디자인 시스템 | Mac OS UI 톤 | Material, Ant | 페르소나(개발자 아닌 실무자)에게 익숙하고 차분한 톤. 둥근 모서리 · 부드러운 그림자 · 반투명 카드를 Tailwind 로 낼 수 있다 | 정해진 컴포넌트 묶음이 없어 톤을 직접 맞춰야 한다 |
| 8 | 테마 | 라이트 / 다크 토글, `localStorage` 저장, 초기값은 **시스템 설정** | 라이트 고정, 서버에 저장 | 처음엔 사용자의 OS 설정을 따르고, 고른 값은 브라우저에 남아 새로고침해도 유지된다 | 기기 · 브라우저마다 따로 저장되고 로그인해도 따라가지 않는다 |

## 2. 화면

### 2.1 화면 배치

배치는 **`docs/화면구성.pdf`** 를 따른다. 여기에 옮겨 적지 않는다.

### 2.2 화면 요소 이름

`docs/화면구성.pdf` 5쪽 id 표를 그대로 옮긴다.
**한 번 정하면 바꾸지 않는다. 바꿔야 하면 사유를 먼저 이 문서에 적는다.**

| 요소 | id | 자리 |
|---|---|---|
| 검색 입력 | `q` · `from` · `to` | 목록 화면 상단 |
| 목록 칸 | `cards` | 카드 배치 구역 |
| 넣기 폼 | `title` · `metAt` · `attendees` | 제목 · 일시 · 참석자 |
| 파일 · 본문 | `file` · `body` | 녹취 파일과 받아쓴 본문 |
| 버튼 | `btnUp` · `btnSave` | 받아쓰기 · 정리 |
| 결과 세 칸 | `result` | 요약 · 결정사항 · 할 일 |
| 상세 창 | `modal` | 카드를 누르면 뜨는 겹침 창 |
| 제목 수정칸 | `mTitle` | 상세 창 안에서 제목을 고치는 칸 |
| 할 일 표 | `todoBody` | 표의 본문 행 |

## 3. 의존성 추가 정책

- **이 문서에 사유를 적기 전에는 어떤 의존성도 도입할 수 없다.**
- 새 의존성이 필요하면 아래 표에 패키지 · 쓰임 · 사유를 먼저 적고 나서 설치한다.

### 3.1 사전 승인 목록

| 패키지 | 쓰임 |
|---|---|
| `fastapi` | 웹 프레임워크. REST API 7개와 프론트 정적 파일 제공 |
| `uvicorn` | FastAPI 를 띄우는 ASGI 서버 |
| `sqlalchemy` | SQLite ORM. Meeting 모델 · 쿼리 (추후 PostgreSQL 전환 대비) |
| `pytest` | 테스트 실행 |
| `httpx` | 테스트에서 API 호출 (FastAPI `TestClient` 가 사용) |
| `google-genai` | Gemini API 호출 - 받아쓰기 · 세 갈래 구분 |
| `python-multipart` | `POST /api/upload` 의 파일 업로드(multipart/form-data) 받기 |
| `python-dotenv` | `.env` 에서 `GEMINI_API_KEY` · `GEMINI_MODEL` 읽기 |

### 3.2 추가 승인 기록

| 날짜 | 패키지 | 쓰임 | 사유 |
